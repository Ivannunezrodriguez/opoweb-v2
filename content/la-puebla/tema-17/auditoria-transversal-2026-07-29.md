## 5. Vigencia técnica

Contraste realizado con documentación oficial vigente:

- Microsoft mantiene Word para Microsoft 365 y Word 2024 entre los productos cubiertos por su documentación actual de saltos de sección;
- Word utiliza saltos de sección para cambiar orientación, encabezados, pies, numeración, columnas y otros elementos de diseño;
- LibreOffice Writer utiliza estilos de página para definir márgenes, orientación, encabezados, pies, fondo y columnas;
- Writer permite aplicar un estilo de página distinto mediante un salto manual;
- la ayuda oficial de Writer mantiene `F5` para activar o desactivar el Navegador y `F7` para ortografía;
- los atajos pueden ser reasignados o entrar en conflicto con el sistema operativo, por lo que no deben tratarse como universales fuera del contexto indicado.
